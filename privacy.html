隱私政策

服務條款

生效日期：【請填生效日期】　·　最近更新：【請填】

本隱私政策說明「虫虫精讀」（下稱「本工具」）如何處理你與孩子的資料。核心原則是：資料以你自己的設備為主，我們（開發者）不架設伺服器、不收集、不上傳、也看不到你的任何內容。

一、我們收集什麼？（幾乎為零）

本工具是一個純前端網頁程式，沒有後端伺服器。你在使用中產生的資料只存在你自己的設備裡：

  • 學習資料：課文、生詞、練習記錄、復習進度、打卡分數、登山進度等，全部存在瀏覽器本機（localStorage / IndexedDB）。
  • 你自己填入的 API 金鑰（智譜 / 微軟 Azure / Google）：只存在你本機，用於直接連到你選擇的服務商。金鑰不會傳給我們，也不會寫入任何我們的伺服器或倉庫。
  • 孩子的錄音：跟讀 / 背句 / 造句的語音，是交給「瀏覽器內建的語音辨識」（在 iPhone/iPad 上由 Apple 處理、在安卓 Chrome 上由 Google 處理）即時轉成文字後比對，本工具不儲存音檔、不上傳錄音。

二、資料會不會傳到外部？（只在你主動時，且是你自己的帳號）

  • 雲端朗讀（可選）：若你自行開啟並填入 Azure / 智譜 / Google 金鑰，課文文字會傳到你選的服務商合成真人語音；這是你與服務商之間的行為，受該服務商的隱私政策約束。
  • 雲備份（可選）：若你自行設定 Gitee / GitHub 私人倉庫同步，學習資料會存到你自己的私人倉庫；只有你能存取。我們沒有你的倉庫權限。
  • AI 生成課文（可選）：你拍照或貼上的課文，會用你自己的金鑰傳給你選的 AI 服務商生成精讀內容。內容由你提供、版權由你負責。

除上述由你主動啟用、且指向你自己帳號的情況外，本工具不會把任何資料傳送到第三方，不含廣告、不做用戶追蹤、不販售任何資料。

三、關於兒童

本工具供家庭在家長陪同下使用。因所有資料存於本機、且不由我們收集，家長對孩子在本機產生的學習資料與錄音的使用擁有完全控制權。家長可隨時依「第五節」刪除全部資料。使用前請家長確認並同意本政策。

四、我們（開發者）能看到什麼？

看不到任何東西。我們不營運伺服器、不接收你的資料。你的學習內容、金鑰、錄音、備份都不經過我們。

五、如何刪除你的資料

  • 刪除單一自建課：在課程目錄長按 / 點該課的 🗑 刪除。
  • 清除全部本機資料：在瀏覽器「設定 → 清除網站資料 / 歷史記錄」中清除本站資料。
  • 雲備份：到你自己的 Gitee / GitHub 倉庫刪除對應檔案。

六、第三方服務

當你啟用相關功能時，會用到以下第三方（皆為你以自己帳號直接使用）：智譜 AI、微軟 Azure 認知服務、Google Cloud、Gitee、GitHub。它們各自的隱私政策以其官方公告為準。
