📖 使用教程 · 說明書

🎯 你是來準備雅思的？這份教程是寫給家長與孩子的精讀站說明。 雅思模組有自己的完整說明（含備考策略、分層背詞順序、每日流程）： → 雅思備考說明

給第一次用的家長與孩子：上面是「三步就上手」，中間是每個功能在做什麼，最下面是常見問題（麥克風、聲音、費用、更新）。

🚀 三步就上手

1
打開首頁，點最上面那條橫幅。
軟體會自動安排「今天該學什麼」——先復盤到期的句子，沒有的話就接著上次沒學完的地方。孩子不用自己選，跟著橫幅走就對了。
2
一課分 9 關，從上往下做。
聽全文 → 逐句精讀 → 生詞卡 → 語法點 → 連詞成句 → 跟讀 → 聽力題 → 背句 → 造句。每做完一關會亮一格進度條，9 格全亮＝這課完成。一次做不完沒關係，下次自動接著上次那關。
3
要用嘴巴的關卡（跟讀、背句），第一次會問麥克風——點「允許」。
說完可以直接按「✅ 我說完了」，不用乾等。想以後不再每次問，看下面〈常見問題〉第一條。

💡 每天一點點比一次背很久更有效。首頁的 🔥 連續天數就是給孩子的鼓勵。

📘 每個功能在做什麼

🏠 首頁「今日學習」卡

最上面那張大卡＝一眼看完成沒 ＋ 直達下一步，兩件事合在一張卡（不再分兩塊重複）：
· ✅ 完成＝今天該學的都做完了（給家長判斷娛樂時間）；
· 📅 先復盤 X 句＝有到期複習要先清；
· ▶️ 開始／繼續「課名」＝接著上次沒學完的關卡。
點這張卡就直達該做的地方，孩子不用自己選。

為什麼：孩子零選擇、不糾結；家長一眼知道今天完成沒。

📅 復盤（艾賓浩斯）

學過的句子會按遺忘曲線在對的時間跳出來讓你再背一次：背對了間隔就拉長（30分鐘→1天→2天→4天→7天→15天→30天→90天），連續背對 8 次就算「牢固」畢業、不再打擾；中途背錯就打回從頭再來。首頁 📅 橫幅會顯示今天到期幾句。

為什麼：背了不復習等於白背；間隔一路拉到 90 天，是為了讓學過的東西真正變成長期記憶。

🎙️ 跟讀 / 背句（語音）

對著麥克風念，軟體聽你念得對不對、打分。念完按「✅ 我說完了」立刻出結果（開始錄音和「我說完了」是同一顆按鈕）。

背句可以先看句子幾秒再蓋住背：「看幾秒」預設「自動」——依句子長短自動調整（短句約 4 秒、長句到十幾秒），也可手動固定 5／10／15 秒；不想看直接背，點 「直接背，不看」。

想要更專業的打分？「🔊 聲音」頁可開 🎯 發音評估（見下方），跟讀／背句會改用 Azure 微軟給 準確度・流利度・完整度・語調四個分數，而不只是一個準確率。（開了之後背句要點「開始背」才錄音，念完點「我說完了」上傳打分。）

為什麼：讀出來才會說；分數只是提示，重點是敢開口。四維評分能看出「念得準不準、順不順、完整不完整、語調自不自然」。

📖 逐句精讀 · 📝 語法點 · 🧩 連詞成句

逐句精讀：一句一句看中文＋講解，每句可單獨🔊朗讀。語法點：把當課重點語法拆開講、配例句。連詞成句：把打亂的詞排回正確句子，排對打勾、看答案會進錯題本。

🗂️ 生詞卡 + 生詞強化練習

生詞卡：看中文/例句，翻面把單詞拼寫默寫出來（look-cover-write-check），拼錯會顯示正解並進錯題本。

生詞強化練習：一遍記不牢，同一批詞換方向多練幾輪——看中文默寫外語讀音（中→外）、看外語選中文（外→中），加大記憶量。

為什麼：認得 ≠ 記得。多方向、多重複才能真的把生詞記進長期記憶。

🎧 聽力題（可開盲聽）

播一句英文，選它的意思或答一個理解問題。答案由軟體嚴格把關過，不會出現「正確答案卻算你錯」的情況。想練純聽力可開「🙈 盲聽」：句子先藏起來、只靠耳朵，聽滿 3 次才給「看一眼」（看過再答對就不計分，鼓勵先用耳朵）。

為什麼：先聽懂再開口；盲聽逼孩子真的用耳朵而不是用眼睛對答案。

✍️ 造句

用當課學到的詞自己造一句，AI 幫你看通不通、給建議；檢查完還會示範一句更地道、更像外國人說法的句子讓你學。

家長可設每句最少詞數（不限制／至少 5 詞／至少 8 詞，在「家長設定」裡），避免每次都造太簡單的短句。

為什麼：會用才算真的學會，不只是認得；限制最少詞數是逼孩子寫出完整、有內容的句子。

➕ 加一課（拍照 / 貼課文 / 貼單詞）

首頁綠色橫幅 → 拍課本照片或貼一段文字 → AI 自動做成完整 9 關精讀頁。需要填一次智譜 API Key（見〈常見問題〉費用那條）。

💡 也可以只貼一組單詞（每行一個，或用逗號分隔，可帶中文意思）——會做成「單詞＋例句＋造句」的背單詞精讀課：每個詞配一個地道例句，一樣能跟讀、背句、造句、聽力練習。

加課頁有 「① 之二·內容類型」：預設「🔎 自動判斷」。如果貼的是一整行用空格分開的單詞（像 apple banana cat），自動判斷分不清是單詞還是句子——這時直接選 「🔤 一組單詞」 就會強制做成背單詞課；反過來，被誤判成單詞的課文可以選「📄 一篇課文」。

為什麼：課本、繪本、任何你有版權的材料都能變成精讀課，不受內建課文限制。自己加的課可以隨時 🗑 刪掉。

🔊 聲音（可選雲端真人語音）

頂部「🔊 聲音」頁可以試聽、挑一個最像真人的朗讀嗓音（英語、日語各選一個）。想更自然可下載系統「增強版」語音。

覺得系統聲還是太機械？頁面頂部有 ☁️ 雲端真人語音，可選語音來源：
· Azure 微軟（推薦）：母語又自然、國內不翻牆可用、iPad/iPhone 也能出聲——學發音的最佳選擇。需填一次 Azure 密鑰+區域（頁面上有申請步驟）。
· 智譜：免申請、用做課那把 key，但英文偏中式腔，不建議用來學發音。
· Google：母語最自然，但需海外條件。
按「▶️ 試聽英文／日文」親耳聽，好聽就打開開關。開了之後全站朗讀都用它——單句（跟讀／背句／生詞／造句／復盤）、聽力題、以及聽全文（整篇連續一次讀完，不再一句一句斷）；念過的句子會快取重播不花錢；沒開或失敗會自動退回系統聲。

🔊 聲音頁還有一個 「📏 聽全文·句間停頓」：控制整篇朗讀時句子之間停多久。預設「🔄 自動跟課文」——對話類自動停短、故事/敘事自動停長；覺得不順再拖滑桿，或點三個預設 💬 對話 180｜📄 標準 260｜📖 故事 400（毫秒），就會切成「手動固定」永久用你設的值，想回自動點一下按鈕即可。

聲音頁還有 🎯 發音評估（四維打分）：打開後，跟讀／背句會把孩子念的那一小段錄音上傳 Azure 微軟評分，回 準確度・流利度・完整度・語調四個分數（比原本單一準確率更專業）。用的是雲端語音同一把 Azure 密鑰，走「語音轉文字」——每月有 5 小時免費額度，一個孩子每天念幾十句遠遠用不完。這四維裡的綜合發音分會照常算進復盤、爬山、總評分，跟原本一樣。

怎麼開：先在上面「☁️ 雲端真人語音」設好 Azure 密鑰＋區域（發音評估和 Azure 朗讀共用同一把）→ 回到 🎯 發音評估 按「開啟」。之後進跟讀／背句：點「開始背」開麥克風 → 念一句 → 點「我說完了」上傳打分。

要知道：①要上傳一小段錄音到微軟（不像不開時純本機）；②第一次用完建議去 Azure 後台（成本管理→篩 Speech）看一眼扣費，數字有延遲、隔天再確認一次（估計 0 元）；③語調那條偶爾不出現是正常的（看 Azure 有沒有回，沒回就只顯示三項）；④沒開或評分失敗，會自動退回原本的本機打分，孩子不會卡住。

為什麼：發音自然是語言學習的關鍵。Azure 母語神經語音發音準又自然，國內實測不翻牆可用，值得設定一次。停頓能調，是因為讀故事和讀對話的節奏本來就不同。

📊 學習報告（給家長）· 日報／週報／月報／年報

怎麼進：首頁最上面那條 🔥 連續學習（寫著「看週報 →」）點一下，就進入「學習報告」頁。

頂部兩排切換鈕：英語／日語分開看、日報／週報／月報／年報切換。週/月/年報看學習量、課程進度、最常錯的地方。

📅 日報：選一天（可用「◀ 前一天／後一天 ▶」翻），一眼看清那天完成了哪些課、每課完整度多少％、得分多少、以及那天新做了哪些環節（生詞卡／跟讀／背句…）。（每日明細是從這個功能上線後才開始記的，之前的日期沒有明細；完整度／得分是「截至那天的累積」。）

為什麼：家長一眼知道學得怎樣、卡在哪，還能看長期趨勢。

🔒 家長設定（複習鎖 · 要密碼）

在哪：就在上面那個「學習報告」頁，拉到最底有一塊「🔒 家長設定」。第一次用先設一個家長密碼（4 位以上，孩子改不了）。

① 複習鎖：可切 「可以直接上新課」（預設）或 「必須複習完才能上新課」——開了之後，只要當天有到期複習沒清完，「加新課」和沒開始的新課就會鎖住（🔒），先去復盤才解鎖；已經在學一半的課不受影響。

② 造句最少詞數：不限制／至少 5 詞／至少 8 詞，控制孩子造句的長度。

為什麼：怕孩子只顧著開新課、不回頭複習，可強制「先還舊帳」；也可要求造句不能太敷衍。

🎯 總評分

每課打卡頁最上面、目錄卡片課名旁邊，會顯示這課的正確率（答對比例）和完成度（做了幾關）。分數只增不減，練得越好越高。

為什麼：一眼看出哪課學紮實了、哪課還要再練。

🏔️ 登山遊戲 + 🎉 鼓勵音效

頂部「🏔️ 登山」：每答對 1 題就往上爬 10 米，從海平面一路爬泰山、富士山……到珠峰。可以選一個登山角色、上傳自己的照片當頭像、定一座想爬的山。答對題目時還會有鼓勵音效和英文誇獎（可在「🔊 聲音」頁關掉）。

為什麼：把「答對題」變成看得見的成就，孩子更有動力。

⬅️➡️ 上一課／下一課

每課打卡頁底部有「上一課／下一課」按鈕，不用回目錄就能直接接著學下一課。

🎌 日語版

頂部可切換到日語精讀（假名標音、日語朗讀）。用法一樣，報告和登山都和英語分開統計。

🎯 雅思詞彙（ielts/）

給誰用：要考雅思的人，目標 6.5。怎麼用：打開就一個按鈕「開始今天的 N 張卡」， 點下去直接背，不用選課、不用設定。先看單詞想意思 → 按「看答案」→ 選「認識／不認識」。

6000 詞分四層，順序有講究： L1 基礎（中考/高考/四級，3277 詞）→ L2 進階（六級/考研，1322）→ L3 雅思獨有（786）→ L4 學術拓展（托福高頻，615）。 雅思核心詞有一半以上落在 L1，所以先補基礎的洞，比直接啃雅思詞彙書有效。

⏭ 這批我都會：L1 前面是 be / the / of 這類最高頻詞，逐張點很浪費時間， 用這顆按鈕一次跳過（會直接標成已掌握不再出現，之後可在複習頁重置）。

複習隊列（ielts/review.html）：看今天到期的詞、各層進度， 可以重置某一層重來（會先問你、並顯示將清除幾筆，重置後 24 小時內可以還原）， 也可以匯出 CSV 丟進 Anki。

間隔怎麼算：和精讀的復盤同一套艾賓浩斯引擎——30分 → 1天 → 2 → 4 → 7 → 15 → 30 → 90天， 答錯就打回重來，連過 8 關算牢固。

⚠️ 資料是分開的：雅思的進度和英語精讀、日語版完全分開存，互不影響。 雲備份也是各存各的檔案，不會互相覆蓋。首頁下方有「隔離自檢」， 顯示「已分家 ✓」就代表正常。

約 200 個詞沒有音標（詞典來源就缺），這些詞按「🔊 發音」照樣能聽，走系統語音。

🎧 精聽聽寫（ielts/dictation.html）： 貼一段聽力原文（劍橋真題文本或任何英文段落），系統切成句子、用語音一句句念， 你打出聽到的內容。音頻不用上傳，用系統語音朗讀，素材留在你自己手上。

重點是錯因分類：對完答案會告訴你錯在哪一類—— 連讀/弱讀（漏掉 to、of、a 這類小詞，雅思最大宗失分）、拼寫、數字、專有名詞、生詞、語速。 累積幾輪後首頁會顯示你最常錯哪一類並給對應練法，照著練比盲目多聽有效。 錯的詞會自動進復習隊列。

✍️ 寫作 Task 2（ielts/writing.html）： 8 個高頻話題的論點庫——正反各 3 個論點、可用例子、高分表達。 這是考場上「組裝」用的彈藥，不是拿來背的範文（背範文會被判雷同，也套不上真題）。

兩層檢查：先按「先自己體檢」（免費、不用 key）——字數不足、引言照抄題目、 缺轉折讓步、連接詞太機械，這些不花一毛錢就抓得到。改完再送 AI 批改， 會給任務回應/連貫/詞彙/語法四項分數 + 指到具體句子的問題與改寫。

⚠️ AI 給分普遍偏高 0.5–1 分——拿它看問題在哪，不要拿它當分數。 用的是「加一課」同一把智譜 key，預設免費的 glm-4-flash。

🗣 口語練習（ielts/speaking.html）： Part 1/2/3 題庫 + 計時器 + 錄音回聽。Part 2 自動跑「1 分鐘準備 → 2 分鐘說」， 說完給時長與語速判讀。說不滿 2 分鐘是最常見的失分，計時器就是為此。

⭐ 素材複用：與其準備 50 個題目，不如把 5 段真實經歷（一次旅行／學會的技能／ 重要的人／困難的經歷／常用的物品）講到滾瓜爛熟——頁面列出每段素材能覆蓋哪些題型。

⚠️ 關於錄音：錄音只留在你這台裝置的瀏覽器裡，不上傳任何伺服器，關掉頁面就沒了。 微信內建瀏覽器不開放麥克風（蘋果／微信的硬限制，不是程式問題）， 請用 Safari／Chrome 開。頁面上方會直接告訴你這台裝置能不能錄。

詞表來源：ECDICT（MIT 授權），含音標、中文釋義、詞頻。 要重建或調整詞量：python3 ielts/build_vocab.py --ecdict ecdict.csv

🙋 常見問題

每次打開都要重新允許麥克風，能不能一勞永逸？
每次重開網頁瀏覽器都會再問一次，這是瀏覽器的安全規定，不是壞掉。想設成基本不再問，照你的設備做一次：

📱 iPhone / iPad：設定 → 通用 → 鍵盤 → 打開「啟用聽寫」；再 設定 → Safari → 麥克風 → 改「允許」。強烈建議把本站「加入主畫面」（Safari 分享鈕 → 加入主畫面），從主畫面圖示打開，權限記得最牢。
💻 Mac Safari：Safari 選單 → 設定 → 網站 → 麥克風 → 把本站設為「允許」。
💻 Mac Chrome：點網址列左邊的 🔒 → 麥克風 → 「允許」，設一次基本不再問。
朗讀的聲音很機械 / 不像真人，怎麼辦？
兩步：
① 換嗓音：頂部「🔊 聲音」頁，按 ▶️ 試聽，挑一個順耳的按「選這個」。
② 下載增強版語音（免費、更自然）：
  iPhone / iPad：設定 → 輔助功能 → 朗讀內容 → 聲音 → 英文（或日文）→ 找標「增強版 / Enhanced」的點雲朵下載。
  Mac：系統設定 → 輔助功能 → 朗讀內容 → 系統語音 → 管理語音，勾選增強版下載。
下載後回「🔊 聲音」頁，新聲音會標「較自然」，選它即可。
※ 若下載後仍沒出現，代表這台設備瀏覽器暫時只開放系統聲音，屬正常限制。
加一課要花錢嗎？怎麼準備 API Key？
內建課文免費；自己「加一課」用 AI 生成才需要智譜（bigmodel.cn）的 API Key。
準備：到 bigmodel.cn 註冊 → 控制台領 API Key → 確認帳戶已充值。Key 只存在你這台設備，不會外傳。
費用：文字用 glm-4-plus（付費，出題／講解質量好），一課大約幾分錢人民幣；拍照識字用免費視覺模型。想省錢可在「進階」把文字模型改成 glm-4-flash（免費，但聽力題會多走保底題）。
更新了但頁面沒變 / 拿不到新版怎麼辦？（怎麼確認在最新版）
正常情況普通刷新就會拿到最新版（已內建網絡優先機制）。想確認自己是不是最新碼：看首頁最底的「版本 日期」——日期越新代表越新。
若還是舊的，按一次硬刷新：
Mac：Cmd + Shift + R。iPhone / iPad：關掉 Safari 分頁重開，或設定 → Safari → 清除歷史紀錄與網站資料。
硬刷新一次之後，之後普通刷新即可。（例如「背句看題秒數好像固定不變」多半就是拿到舊碼，硬刷新即可。）
日語背句 / 跟讀打不到分，還說「你說的是英語」？
這台設備沒開「日語聽寫」——系統把日語當成別的語言聽了，不是軟體壞。開啟：
iPhone / iPad：設定 → 通用 → 鍵盤 → 鍵盤 → 加入「日文」鍵盤，並確認「啟用聽寫」已開 → 完全關閉 Safari 再重開本頁。
不確定設備行不行？跟讀/背句出錯時點「語音診斷」連結（或直接開 jp-mic-test.html），會告訴你這台能不能聽日語。真的不支援就先用「我背對了／沒背對」自評。
發音評估（四維打分）要花錢嗎？
用的是雲端語音同一把 Azure 密鑰，走「語音轉文字」——每月有 5 小時免費額度，一個孩子每天念幾十句，一個月估計 1 小時出頭，用不完＝基本免費。
要不要放心？第一次用完，去 Azure 後台 → Cost Management（成本管理）→ Cost analysis看一眼實際扣費（可「新增篩選 → 服務名稱 → Speech」單獨看）。⚠️Azure 費用數字有 8～24 小時延遲，剛用的可能還沒顯示成「--」，隔天同一時間再看一次才算數；建議把「範圍」切到訂閱層級看全部，免得語音服務不在這個資源群組而漏看。對一次帳就安心了。沒開這個功能時，跟讀/背句是純本機打分、完全不上傳、不花錢。
自己加的課想刪掉？
首頁「我的課文」區，每課右邊有 🗑 刪除鈕。刪除會一併清掉該課的學習進度和錯題，內建課文不受影響。
換一台設備，學習紀錄還在嗎？
紀錄預設存在當前這台設備上。開啟雲端備份（首頁同步卡）後，換設備登入同一份就能接著學、週報也同步。沒開雲端就只在本機。
怎麼開啟雲端備份？（國內推薦 Gitee）
首頁「☁️ 雲端備份未開啟」卡 → 點「開啟」，選雲端服務：
· Gitee 碼雲（國內·不翻牆·推薦）：到 gitee.com 免費註冊 → 建一個私有倉庫叫 jingdu-data → 設置 →「私人令牌」勾「projects」生成令牌 → 把令牌貼進軟件。國內連線穩定。
· GitHub：同樣建私有倉庫 jingdu-data + fine-grained token，但國內連 GitHub 不穩、偶爾要重試。
令牌只存這台設備、不外傳。每台設備用同一個暱稱＝同一份進度，換機也接得上。
沒網路能用嗎？
已學過、打開過的課文可以離線複習（跟讀評分、聽力播放靠系統，通常也能用）。但「加一課」要連 AI、雲端備份要連網，這兩項需要網路。
聽力題答案還是覺得不對？
如果是硬刷新前生成的舊課，可能還帶著舊版毛病。請先按上面〈更新〉硬刷新一次，把那課刪掉重新生成一門，新版的把關機制會保證答案正確。
