日語語音識別診斷

用來測「這台設備能不能做日語語音識別」。請用 Safari 開，並先按一次下面的按鈕、對著麥克風念一句日語（例如「おはよう ございます」）。下面會把識別到的原文、是不是日文、報什麼錯，全部原樣顯示。

看不到日文 / 聽成英文？這樣開日語聽寫：

  1. iPhone/iPad：設定 → 通用 → 鍵盤 → 鍵盤 → 加入新鍵盤 → 日文
  2. 回到 設定 → 通用 → 鍵盤，確認 「啟用聽寫」 已打開
  3. 完全關閉 Safari 再重開本頁，重新測一次
  4. 若還是不行：這台設備/系統版本可能不支援日語聽寫，背句就用「自評」按鈕（我背對了／沒背對）
